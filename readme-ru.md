## Описание

JS Blocker - это расширение для браузера Safari. JS Blocker по умолчанию блокирует JavaScript на выбранных веб-сайтах. Открывая неизвестный веб-сайт, Вы можете быть уверены, что на нём не будет выполняться JavaScript, пока Вы не разрешите его выполнение (подробнее в разделе "Режимы работы расширения в Safari"). Блокировка не позволяет потенциальным майнерам, кейлоггерам и другим вредоносным программам на JavaScript, работать без вашего разрешения. JS Blocker не может определить, является ли JavaScript вредоносным!

Чтобы разрешить выполнение JavaScript на определённом веб-сайте, пользователь с помощью всплывающего окна JS Blocker добавляет этот веб-сайт в список разрешённых.

Добавить веб-сайт в список разрешённых можно и временно, на один из следующих периодов: 1 минуту, 5 минут, 1 час, 1 день или 1 неделю. Также поддерживается функция выборочного включения JavaScript — Вы сами указываете, в каком окне какой JavaScript будет разблокирован.

### Режимы работы JS Blocker

JS Blocker поддерживает 4 режима работы:

- разрешить JavaScript на сайте: `JavaScript на Домене`;
- разрешить JavaScript на сайте, раздельно по скриптам: `JavaScript на Домене` + опция `Разрешать JS раздельно по скриптам`;
- разрешить JavaScript на сайте и его доменах: `JavaScript на Домене + Поддомены`;
- разрешить JavaScript на сайте и его доменах, раздельно по скриптам: `JavaScript на Домене + Поддомены` + опция `Разрешать JS раздельно по скриптам`.

### Режимы работы JS Blocker Safari Extension

Если в настройках Safari для этого расширения выбраны значения `Сайт N = Разрешить / Для других сайтов = Разрешить`, тогда JavaScript будет блокироваться на всех веб-сайтах и во всех их окнах. Это рекомендуемый и самый надёжный режим работы.

Если в настройках Safari для этого расширения выбраны значения `Сайт N = Разрешить / Для других сайтов = Запретить`, тогда JavaScript будет блокироваться только на выбранных веб-сайтах. Если на таких веб-сайтах открыты окна с других веб-сайтов, на которых это расширение не было включено, JavaScript в этих окнах продолжит выполняться, поскольку расширение не сможет получить к ним доступ и заблокировать JavaScript.

### Типы блокируемого JavaScript

JS Blocker блокирует следующие типы JavaScript:

- любой внешний JavaScript, загружаемый с текущего веб-сайта;
- любой внешний JavaScript, загружаемый с других веб-сайтов;
- любой встроенный (embedded) JavaScript, находящийся непосредственно в HTML-документе внутри тегов `script`;
- любой линейный (inline) JavaScript в атрибутах, названия которых начинаются с `on…=…` (такие атрибуты удаляются);
- любой линейный (inline) JavaScript в атрибутах, значения которых начинаются с `javascript:` (такие атрибуты удаляются);
- любой iframe с атрибутом `srcdoc` удаляется;
- любой iframe с атрибутом `src`, значение которого начинается с `data:text/html`, удаляется;
- любой iframe с атрибутом `src`, значение которого начинается с `data:application/xhtml+xml`, удаляется;
- любой iframe с атрибутом `src`, значение которого начинается с `blob:`, удаляется.

Если на веб-сайте есть окна, в которых присутствует JavaScript любого из перечисленных выше типов, к этому JavaScript применяются те же правила блокировки.

Учтите, что разрешённый JavaScript может динамически подключать другой JavaScript с любого веб-сайта или динамически создавать окна. JS Blocker не отслеживает эти действия, поскольку считает такой JavaScript доверенным, а все его последующие действия — разрешёнными и одобренными пользователем.

После добавления веб-сайта в список разрешённых перечисленные выше блокировки JavaScript к нему не применяются.

### Поддерживаемые адреса

JS Blocker поддерживает следующие виды адресов (доменных имён) в Safari:

- короткие локальные (например, `http://localhost`);
- классические (например, `http://example.com`);
- классические с поддоменами (например, `http://subdomain.example.com`);
- интернациональные доменные имена (например, `http://пример.com` = `http://xn--e1afmkfd.com`);
- интернациональные доменные имена с интернациональной доменной зоной (например, `http://пример.ком` = `http://xn--e1afmkfd.xn--j1aef`);
- в виде IPv4-адреса (например, `http://127.0.0.1`);
- в виде IPv6-адреса (например, `http://[::1]`).

Номер порта в адресе игнорируется.

### Поддерживаемые ОС

Поддерживаются следующие версии macOS:

### Дополнительная информация

JS Blocker является программным обеспечением с открытым исходным кодом.  
JS Blocker не использует модель подписки.  
JS Blocker не содержит кода, сгенерированного ИИ.
