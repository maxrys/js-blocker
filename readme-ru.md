
Это расширение с открытым исходным кодом блокирует JavaScript на всех веб-сайтах. Используя "Разрешённый список", пользователь решает, каким веб-сайтам разрешен JavaScript.

## Описание

Если это расширение Safari включено для любых веб-сайтов (режим работы расширения "Для других сайтов = Разрешить"), тогда, по умолчанию, оно блокирует JavaScript на любых веб-сайтах. Это рекомендуемый режим работы.

Если это расширение Safari включено только для выбранных веб-сайтов, тогда, по умолчанию, оно блокирует JavaScript только на выбранных веб-сайтах.

С помощью настроек расширения пользователь может добавить веб-сайт в "Разрешённый список".
Веб-сайт из "разрешённого списка" сможет использовать JavaScript.

Добавить веб-сайт в "Разрешённый список" можно и временно, на следующие периоды:
- 1 минута;
- 5 минут;
- 1 час;
- 1 день;
- 1 неделя.

Открывая неизвестный веб-сайт, Вы будете уверены, что никакой JavaScript на нём не будет выполнен, пока Вы это не одобрите (если для расширения Вы выбрали режим работы "Для других сайтов = Разрешить").
Это гарантирует, что потенциальные майнеры, кейлоггеры или любые другие злонамеренные программы, написанные на JavaScript, не смогут работать, пока Вы это не одобрите.
Учтите, что данное расширение не способно определить, является ли JavaScript злонамеренным.

По умолчанию для текущего веб-сайта следующие типы JavaScript будут заблокированы:
1) любой внешний JavaScript с текущего веб-сайта;
2) любой внешний JavaScript с других веб-сайтов;
3) любой встроенный JavaScript (может находиться непосредственно в HTML-документе, в тегах `script`);
4) любой линейный (событийный) JavaScript (может находиться непосредственно в HTML-документе, в атрибутах с названиями, начинающимися на `on…=…`);
5) JavaScript во frame/iframe, любого вышеперечисленного типа, с любого веб-сайта.

После внесения сайта в "Разрешённый список" все вышеперечисленные блокировки JavaScript не будут применяться.

Это расширение поддерживает следующие виды адресов (доменных имён) в Safari:
- короткие локальные (например, `http://localhost`);
- классические (например, `http://example.com`);
- классические с поддоменами (например, `http://subdomain.example.com`);
- интернациональные (например, `http://пример.com` = `http://xn--e1afmkfd.com`);
- интернациональные полные (например, `http://пример.ком` = `http://xn--e1afmkfd.xn--j1aef`);
- в виде IPv4-адреса (например, `http://127.0.0.1`).

Адреса вида IPv6 не поддерживаются.
Номер порта в адресе игнорируется.

Поддержка следующих версий macOS:
- 11 (Big Sur)
- 12 (Monterey)
- 13 (Ventura)
- 14 (Sonoma)
- 15 (Sequoia)
- 26 (Tahoe)
и выше.
